Lets Design Whatsapp 
=======================
1. One to One Messaging 
2. User enters the application and login with email, they login with otp.
3. Setup Azure Entra ID, App resigration for UI application with redirect url
4. User should be able to access the My profile page.
5. Client should get the access token of API userService registration
6. from user service access the database and fetch user details
7. navigate to chat section.
8. Invite friend button
9. Search user with email id 
10. User service will have its own database of users. 
11. From there it will get the user.
12. User open the chat of user.
13. It hits chat api server with the access token.
14. There should be chat dtaabase with table having sender Id, Receiver Id, message, 
15. In Ui all the messages should be displayed order by date.
16. User type and send the message to receiver.
17. it hits the message signalR service in dot net. 
18. signalR service checks if receiver is online or not.
19. if user is not online then the message is sent to azure service bus queue.
20. When user comes online he receives notification. 
21. for offline user sends firebase push notification
22. all the recent messages should be stored in redis
